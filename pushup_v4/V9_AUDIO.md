# V9 Audio

The battle SFX in `app/src/main/res/raw` were regenerated as original procedural game sounds for this project (not placeholder beeps).

They are intentionally short and mix-friendly: impacts, rising combo tones, overtake stingers, countdown, victory/defeat, opponent activity, and connection feedback.

The existing `BattleAudioManager` event names are preserved so no gameplay wiring changes are required.
